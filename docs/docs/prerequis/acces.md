# Accès à l'application

L'application **Autorisations** est une application Web interne accessible depuis **n'importe quel navigateur**. Elle est conçue pour être utilisée sur un ordinateur, connecté au réseau du Parc.

---

L'application est disponible à l'adresse : **http://autorisations.pnrun.local**

Pour pouvoir y accéder, il est nécessaire d'être connecté au réseau interne du Parc national, via l’un des moyens suivants :

- connexion **filaire** ;
- connexion **Wi-Fi PNRUN** ;
- connexion **VPN** (pour un accès distant).

Sans connexion au réseau interne, l’application n’est pas accessible.
