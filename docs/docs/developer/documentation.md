# Bienvenue dans MkDocs

Pour consulter la documentation complète, rendez-vous sur :  
[https://www.mkdocs.org](https://www.mkdocs.org)

## Commandes principales

- `mkdocs new [nom-dossier]` — Crée un nouveau projet MkDocs.
- `mkdocs serve` — Lance le serveur de documentation en mode développement (avec rafraîchissement automatique).
- `mkdocs build` — Génère les fichiers statiques de la documentation dans un dossier 'site'
- `mkdocs -h` — Affiche le message d’aide.

## Structure du projet

    mkdocs.yml    # Le fichier de configuration.
    docs/
        index.md  # La page d’accueil de la documentation.
        ...       # Autres pages Markdown, images ou fichiers supplémentaires.
