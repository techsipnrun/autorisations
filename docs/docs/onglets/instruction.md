# Onglet « Instruction »

## Tableau d'instruction

Le tableau d'instruction permet d'avoir **une vision générale de l'instruction des dossiers**, tout type confondu, **sur l'année en cours**.
Pour chaque type de dossier on peut voir :

- le nombre de dossier en *Réception*
- le nombre de dossier en *Instruction* (cela inclut les dossiers en pré-instruction)
- le nombre de dossier *traités cette année*

Si vous avez une action à faire sur un ou plusieurs dossiers, alors vous verrez une pastille rouge à gauche du type de dossier concerné.
Pour plus de détails sur le fonctionnement des notifications, consulter la page [Notifications](../dossier/notifications.md).

Au-dessus de ce tableau se trouve le bouton de synchronisation générale. Pour en savoir davantage, rendez-vous sur la page [Synchronisation des données](../onglets/reception.md#synchronisation-des-donnees).


## L'instruction pour un type de dossier

### Actualiser les dossiers d'un même type

Si on clique sur une ligne (qui correspond à un type de dossier) du tableau d'instruction, on arrive sur une page dédiée au type de dossier ciblé.
En haut de cette page, on trouve un bouton «Actualiser».

Ce bouton permet, **pour les dossier du type ciblé uniquement**, de synchroniser les données avec **Démarche Numérique**. Cela permet, pour cet échantillon de dossiers, de garantir la cohérence et l’actualité des informations telles que les données des formulaires et des messageries.
  


### Tableau des dossiers en instruction


Dans le tableau principal on voit tous les dossiers de ce type qui sont en cours d'instruction.

Si vous avez une action à effectuer sur l'un d'eux ou si le dossier comporte un ou plusieurs messages non lus du pétitionnaire, des notifications peuvent apparaitre.
Pour plus de détails sur le fonctionnement des notifications, consulter la page [Notifications](../dossier/notifications.md).

---

Ce bouton switch permet d’**afficher uniquement les dossiers qui me concernent**, c’est-à-dire les dossiers pour lesquels j’ai l’un des rôles suivants :

- instructeur.rice
- membre du groupe instructeur
- validant.e
- intermédiaire signature
- publieur.se RAA
- envoyeur.se d'acte
- relecteur.rice
- relecteur.rice qualité
- signataire


### Tableau des dossiers archivés

En dessous du tableau principal se trouve le tableau des **dossiers archivés**.
Par défaut ce sont les dossiers archivés de l'année en cours qui apparaissent, mais rien ne vous empêche de regarder les dossiers archivés des années passées grâce au **menu déroulant «Année»**.
